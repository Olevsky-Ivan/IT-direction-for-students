Підбір ІТ-напрямку для студентів

Студент заповнює, що вже вміє і що йому цікаво. Програма порівнює цей профіль із вимогами напрямків і показує, куди він лягає краще: розробка, дані чи кібербезпека. Біля кожної рекомендації видно рівень відповідності.

Курсова робота з дисципліни «Об'єктно-орієнтоване програмування».

Як це зібрано

Обчислення живе в ядрі на C++: класи напрямків, пошук, сортування і сам підбір. Сторінки написані на Python. Користувач працює у браузері, а розрахунок виконує ядро. Python лише передає профіль і показує готовий список.

Структура

cpp/ — ядро. У include/career/ і src/ лежать класи предметної області, пошук і сортування. bindings/ збирає це в один модуль career_core, який імпортує Python. tests/ перевіряє ядро окремо від сайту.

app/ — сайт на FastAPI, розкладений по шарах:

api/routers/ приймає запит зі сторінки;
schemas/ перевіряє дані форми;
crud/ читає і пише базу;
models/ описує таблиці;
db/ тримає підключення;
services/career_service.py єдиний викликає career_core.

templates/ — HTML-сторінки, у які Python підставляє результат з ядра. static/ — стилі. data/ — початковий перелік напрямків.

Зараз це каркас. Запуск і збірка з'являться разом із першою робочою версією.
