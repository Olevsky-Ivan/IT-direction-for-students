🎯 Підбір ІТ-напрямку для студентів

Студент уже трохи вміє: десь інтерфейси, десь бази, десь мережі. Він записує це в профіль і додає, що йому цікаво. Програма ставить профіль поруч із вимогами напрямків і показує, куди він лягає краще. Біля кожної поради стоїть рівень відповідності.

🎓 Курсова робота з дисципліни «Об'єктно-орієнтоване програмування».

⚙️ Як це зібрано

Розрахунок живе в ядрі на C++: класи напрямків і підбір за вимогами. Сторінки написані на Python. Користувач працює у браузері, а рахунок веде ядро. Python передає профіль усередину і повертає готовий список на екран.

📁 Структура

cpp/ — ядро. У include/career/ і src/ лежать класи предметної області. bindings/ збирає їх в один модуль career_core, який імпортує Python.

app/ — сайт на FastAPI. routers приймає запит, schemas перевіряє форму, crud і models працюють із базою, db тримає підключення, services/career_service.py викликає ядро.

templates/ — сторінки. static/ — стилі. data/ — початковий перелік напрямків.
